# 竞彩数据源摸底

记录时间：2026-11-26。全部为当日实测，状态码与字段来自真实响应，不是推测。

## 站点

| 站点 | 性质 | 服务端可抓 | 备注 |
|---|---|---|---|
| `www.sporttery.cn` | 竞彩网，竞猜游戏官方发布平台 | 是（curl 200） | 足球/篮球/数字彩都有，无 WAF |
| `webapi.sporttery.cn` | 体彩 JSON 网关 | 是 | 不需要 cookie，不带 Referer 也能拿 |
| `www.lottery.gov.cn` | 中国体彩网 | **页面 403**（腾讯 EdgeOne WAF） | 但 `/tz_kj.json` 直连 200，可当数字彩快照兜底 |
| `cwl.gov.cn` | 福彩（双色球） | 是 | 与竞彩无关，另表记录 |

结论：竞彩抓取不需要浏览器，不需要过验证码。Actions 跑得动。

## 赛果字段

足球（`getUniformMatchResultV1`）：

```
matchId 2043014, matchNum 3011, matchNumStr 周三011, matchDate 2026-11-26
leagueName 英格兰冠军联赛, homeTeam 斯托克城, awayTeam 米尔沃尔
h 1.95, d 3.00, a 3.42            ← 胜平负赔率
goalLine "-1"                      ← 让球数，负=主队让球，整数
sectionsNo1 "2:0"                  ← 半场比分
sectionsNo999 "2:1"                ← 全场比分
winFlag "H"                        ← 彩果 H/D/A
poolStatus "Payout", matchResultStatus "2"
```

篮球（`getUniformMatchResultV1`）：

```
finalScore "107:105", goalline "-2.50"
oneScore/fourScore/threeScore 分节比分
h 1.65, a 1.75                     ← 无平局
winFlag
```

传统足彩（`getFootBallDrawInfoV1`）：`lotteryDrawResult` 是**赛果串**，不是单个结果。例：半全场 `"3 3 0 0 1 3 0 3 1 1 3 1"`。`gameNo` 94=14 场胜负、90=任九、98=6 场半全场。

## 玩法 → 字段映射

| 玩法 | 结算依据 |
|---|---|
| 足球胜平负 | `winFlag` |
| 足球让球胜平负 | `homeScore + goalLine` 后比大小，得 H/D/A |
| 足球比分 | `sectionsNo999`，命中精确比分或"其他胜/平/负" |
| 足球总进球 | `sectionsNo999` 求和，0–6 逐档，7+ 归高档 |
| 足球半全场 | `sectionsNo1` 与 `sectionsNo999` 拼成 9 种组合之一 |
| 篮球胜负 | `finalScore` 比大小，无平 |
| 篮球让分胜负 | `finalScore + goalline`（小数盘） |
| 篮球大小分 | `finalScore` 求和对比盘口 |
| 篮球胜分差 | `finalScore` 差值落档 |

## 结构差异（为什么不能和数字彩同一套模型）

数字彩是「一注号码 vs 一组开奖号」，纯查表，无时间维度。

竞彩是「matchId + 玩法 + 选择 + 盘口」，天然带多场串关：2串1、3串1、混合过关。一个票单含 N 场，全中才中，奖金 = 2 元 × 各场 SP 连乘 × 倍数 × 65% 返奖。判定必须先按场次拆开算单场命中，再按过关方式组组合数。

## 坑

1. **赔率会浮动**。`h/d/a` 是当前赔率，竞彩是固定奖金——出票时的 SP 才算数。所以记票时必须把出票赔率写进票单，不能开奖后回查补；回查只能用来核对。
2. **`clientCode=3002` 无效**，篮球也用 `3001`，靠 `uniform/football|basketball` 路径区分。
3. **足球让球是整数**（-1、+2），有让平；**篮球让分是小数**（-2.50），无走盘。两者结算逻辑不能共用。
4. **淘汰赛只算 90 分钟**，不含加时和点球。比分与总进球都按 90 分钟。
5. `poolStatus` 为 `Payout` 才表示已派彩，`matchResultStatus=2` 表示赛果已定。
6. 体彩首页 `/dlt` 这类子路径会 403 或跳统一错误页，取数别走页面，直接走 `webapi`。
7. 传统足彩整体是串，14 场一等奖要全中、二等奖中 13 场；跟竞彩单场不是一回事，建模时单列。

## 对二期的落点

- `core/matches/` 放单场结算纯函数：输入 `{goals, halfGoals, goalLine, market, selection}`，输出命中/不中/走盘。
- 过关在 `core/parlay.js`：输入 N 个单场结果 + 过关方式，输出组合命中数与奖金。
- 票单模型 `kind: 'parlay'`，`legs[]` 每条带 `matchId + market + selection + sp`，`sp` 出票即冻结。
- 抓取侧只负责把赛果和盘口落到 `draws/matches/YYYY-MM-DD.json`，判定全在 core。
